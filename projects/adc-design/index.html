Computational ADC Design

Scientific notes & limitations

What is real

The antibody coordinates (1HZH), the native glycan residues, and each small-molecule geometry are deposited, publicly available crystal-structure data fetched from RCSB at runtime.

What is schematic

Components come from unrelated structures and are positioned along an axis from the chosen atom. The connecting cylinders are not covalent bonds, so the assembly is a conceptual visualization, not a chemically valid conjugate.

Engineered cysteine

S239C and A114C follow published THIOMAB-style positions. This structure carries the native residue there, so the site is shown for illustration, not as a resolved mutant.

Not modeled

Drug-to-antibody ratio, conjugation chemistry and kinetics, linker cleavage, payload release, aggregation, pharmacokinetics, and any biological activity. One heavy chain is decorated per site; the real antibody is symmetric.

03

Structural references & attribution

Antibody: PDB 1HZH — Saphire et al., Science 293:1155 (2001). Engineered-cysteine positions S239C / A114C follow Junutula et al., Nat. Biotechnol. 26:925 (2008) — this structure has the native residue there, shown for illustration rather than a resolved mutant.

Sugar chain: the real N-glycan residues already resolved on this antibody’s own heavy chain (native to PDB 1HZH) — not a separately fetched structure.

Click handles: azide — real azide-ion coordinates from PDB 1AZI, horse-heart azidometmyoglobin (Maurus et al., Biochem. J. 332:67, 1998). Alkyne — real coordinates of L-propargylglycine, a genuine terminal-alkyne amino acid, from PDB 1I29 (Mihara et al., J. Biochem. 131:679, 2002).

PEG linker: real tetraethylene-glycol coordinates from PDB 2BLX, hen egg-white lysozyme (Nanao et al., Acta Crystallogr. D 61:1227, 2005) — standing in for a PEG-based linker.

Payloads: real deposited ligand geometry from drug–tubulin crystal structures — MMAE from PDB 5IYZ (Waight et al., PLoS ONE 2016); DM1 (as its L-DM1-SMe analog) from PDB 7E4Q (Li et al., BBRC 2021).

Other public references from the earlier version of this project (not used by the current builder; descriptions carried over as originally written and not re-verified): 1IGT (intact IgG), 9Z0F (Fc linker–payload reference), 4K3J.

Requires network access to cdnjs.cloudflare.com (3Dmol.js), files.rcsb.org and models.rcsb.org. The original standalone reference file is kept in reference/ for provenance.
